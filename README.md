## 2. Ядро математических операций (`student_ops.py`)

Модуль [`student_ops.py`](student_ops.py) объединяет 10 автономных функций без использования высокоуровневых "черных ящиков", протестированных в [`test_student_ops.py`](test_student_ops.py) против PyTorch и SciPy:

1. **`centered_similarity(A, B)`**: Центрированное косинусное сходство (NCC / коэффициент корреляции Пирсона). Инвариантно к аффинным преобразованиям интенсивности $I' = aI + b$.
   $$\text{NCC}(A, B) = \frac{\sum (A - \bar{A})(B - \bar{B})}{\sqrt{\sum (A - \bar{A})^2 \sum (B - \bar{B})^2}}$$
2. **`correlate_valid(image, kernel)`**: Точная 2D кросс-корреляция в режиме `valid` (без паддинга): $\text{Out}[y, x] = \sum_{i, j} I[y+i, x+j] K[i, j]$.
3. **`linear_convolution_fft(image, kernel)`**: Линейная двумерная свёртка через 2D БПФ (FFT) с заполнением сетки до $(H + k_H - 1, W + k_W - 1)$ для предотвращения эффекта круговой свёртки (wrap-around aliasing). Невязка со `scipy.signal.convolve2d`: $\le 5.28 \times 10^{-15}$.
4. **`gabor_kernel(ksize, sigma, theta, lambd, gamma, psi)`**: Генерация 2D ядер Габора (моделирующих первичную зрительную кору V1) с гармонической несущей частотой и гауссовой эллиптической огибающей.
5. **`binary_local(image, kernel_size, c)`**: Адаптивная локальная бинаризация: $I(x, y) > \mu_{\text{local}}(x, y) - c$.
6. **`grey_local(image, kernel_size, method)`**: Вычисление локального среднего (`mean`) и локального контраста / среднеквадратичного отклонения (`std`).
7. **`pool2d(image, kernel_size, stride, mode)`**: Пространственный 2D пулинг (`max` и `avg`) с поддержкой произвольного страйда.
8. **`conv_output_size(input_size, kernel_size, padding, stride, dilation)`**: Канонический расчет выходного разрешения сверточных тензоров:
   $$H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2p - d(k - 1) - 1}{s} \right\rfloor + 1$$
9. **`softmax_ce(logits, targets)`**: Численно устойчивый Softmax через Log-Sum-Exp трюк и Cross-Entropy loss с точным аналитическим градиентом $\frac{\partial \mathcal{L}}{\partial z} = \frac{p - y}{N}$. Невязка с PyTorch: $\le 1.39 \times 10^{-17}$.
10. **`correlate_backward(d_out, image, kernel)`**: Обратный проход 2D корреляции: аналитический расчет тензоров частных производных $\frac{\partial \mathcal{L}}{\partial I}$ и $\frac{\partial \mathcal{L}}{\partial K}$ (проверено методом конечных разностей с точностью $\le 1.21 \times 10^{-9}$).

## 3. Сводный обзор лабораторных работ (1–10)

### Лабораторная 1: Изображение как матрица и цветовые каналы
- **Цель:** Изучение тензорной структуры $H \times W \times C$, специфика BGR vs RGB, взвешенная яркость sRGB и арифметика с насыщением.
- **Математическая модель:** Взвешенное преобразование яркости по стандарту ITU-R BT.601:
  $$I_{\text{gray}} = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$
- **Результаты:** 
  - На эталонном `camera.png` получено: размер $512 \times 512$, значение пикселя $(x=100, y=70)$ равно $207$.
  - Абсолютная разность между OpenCV `cvtColor` и собственной векторной формулой: $\max = 1$, средняя невязка $= 0.000656$.
  - Доказано, что беззнаковое сложение в `uint8` приводит к циклическому переполнению по модулю 256 ($(240 + 35) \pmod{256} = 19$). Применение `np.clip` устраняет артефакты, но делает оператор нелинейным из-за эффекта насыщения.

### Лабораторная 2: Свёртка, корреляция и граничные условия
- **Цель:** Ручная реализация пространственной корреляции, физический смысл импульсного отклика, граничные условия и проверка линейности.
- **Математическая модель:** Взаимосвязь корреляции и свертки через инверсию осей ядра:
  $$(I * K)[x, y] = (I \star K_{\text{rot180}})[x, y], \quad K_{\text{rot180}}[i, j] = K[-i, -j]$$
- **Результаты:**
  - Ручная функция `correlate2d_manual` на тестовой матрице $5 \times 5$ показала нулевую невязку с `cv2.filter2D` ($\text{MAE} = 0.00 \times 10^0$).
  - На дельта-импульсе `impulse.png` наглядно визуализировано, что корреляция оставляет ориентацию ядра неизменной, а свертка разворачивает ее на 180°.
  - Численно доказана линейность во `float32`: $\max |T(aI + bJ) - (aT(I) + bT(J))| = 9.54 \times 10^{-7}$.
  - Сравнение граничных условий (`CONSTANT`, `REFLECT`, `REPLICATE`) на фрагменте $30 \times 30$ показало, что нулевой паддинг искусственно затемняет углы, тогда как `REFLECT` сохраняет естественную структуру яркости.

### Лабораторная 3: Модели шума и пространственная фильтрация
- **Цель:** Сравнительный анализ эффективности линейных (Box, Gaussian) и нелинейных (Median) фильтров при подавлении гауссова и импульсного шума.
- **Математическая модель:** Метрики качества восстановления MSE и PSNR:
  $$\text{MSE} = \frac{1}{HW} \sum_{x, y} (I_{\text{orig}} - I_{\text{denoised}})^2, \quad \text{PSNR} = 10 \log_{10}\left(\frac{255^2}{\text{MSE}}\right) \text{ дБ}$$
- **Результаты:**
  - **Для аддитивного нормального шума ($\sigma = 22$):** Наилучший результат показал **Gaussian фильтр ($\sigma = 0.8$)** с $\text{PSNR} = \mathbf{27.74\text{ дБ}}$ ($\text{MSE} = 109.50$).
  - **Для биполярного импульсного шума («Соль и перец», 7%):** Линейные фильтры оказались неэффективны ($\text{PSNR} \le 24.87\text{ дБ}$), размывая выбросы в серые пятна. Абсолютным лидером стал **Median фильтр ($5 \times 5$)** с $\text{PSNR} = \mathbf{27.79\text{ дБ}}$ ($\text{MSE} = 108.18$), полностью устранивший 100% импульсных дефектов.

### Лабораторная 4: Дифференциальные операторы и контурный анализ
- **Цель:** Изучение пространственных производных 1-го (Sobel) и 2-го (Laplace) порядка, расчет векторных полей градиентов и влияние текстуры.
- **Математическая модель:** Модуль и фаза вектора градиента:
  $$|\nabla I| = \sqrt{G_x^2 + G_y^2}, \quad \theta = \operatorname{atan2}(G_y, G_x) \pmod{180^\circ}$$
- **Результаты:**
  - Карты $G_x$ и $G_y$ вычислены в представлении `CV_32F` с сохранением знака. Модуль градиента для `coins.png` достиг максимума $850.72$.
  - Рассчитаны адаптивные квантильные пороги: $q_{0.70} = 56.57$, $q_{0.85} = 132.74$, $q_{0.95} = 303.04$. Порог 85% формирует замкнутые четкие контуры монет без фонового шума.
  - Установлено, что Лапласиан из-за квадратичного усиления частот ($\propto \omega^2$) генерирует паразитные контуры на текстуре `brick.png`. Предварительное гауссово сглаживание ($\sigma = 1.0, 2.0$) устраняет текстурный шум, стабилизируя границы.

### Лабораторная 5: Поиск шаблона и нормированная взаимная корреляция (NCC)
- **Цель:** Исследование нормированной корреляции для локализации объекта, сверка с Ground Truth и оценка устойчивости к освещенности и масштабу.
- **Результаты:**
  - Алгоритм `cv2.matchTemplate(..., TM_CCOEFF_NORMED)` вернул максимум $R = 1.0000$ в координатах $(x=327, y=152)$, что **со 100% точностью совпало с эталоном `ground_truth.txt`**.
  - Метод `TM_SQDIFF_NORMED` показал минимум $R = 0.0000$ в той же точке.
  - **Устойчивость к освещенности:** При аддитивном сдвиге яркости сцены на $+25$ координата объекта осталась неизменной $(327, 152)$, а коэффициент корреляции составил $0.9998$ (доказана инвариантность L2-нормировки).
  - **Неустойчивость к масштабированию:** При масштабировании шаблона на $\pm 15\%$ значение NCC упало до $0.4556$ и $0.3721$ со срывом локализации.

### Лабораторная 6: 2D БПФ, частотная фильтрация и алиасинг
- **Цель:** Исследование 2D дискретного преобразования Фурье, синтез низкочастотных и высокочастотных фильтров, демонстрация стробоскопического эффекта и алиасинга.
- **Результаты:**
  - Построены логарифмические амплитудные спектры $\log(1 + |F|)$ для `fine_stripes.png` и `brick.png`, выявившие периодические гармоники текстурной решетки.
  - Высокочастотный остаток $I - \text{GaussianBlur}(I)$ выделил микрорельеф и граничные детали (принцип Unsharp Masking).
  - **Эксперимент по субдискретизации в 4 раза:**
    - Наивный срез `[::4, ::4]` привел к катастрофическому алиасингу и муару из-за нарушения критерия Найквиста-Котельникова.
    - Масштабирование через `cv2.INTER_AREA` корректно интегрировало энергию пикселей в окне выборки, полностью устранив артефакты муара.

### Лабораторная 7: Свёрточные слои PyTorch как обучаемые фильтры
- **Цель:** Сопоставление `nn.Conv2d` и `cv2.filter2D`, построение многоканального банка фильтров и расчет параметрической сложности.
- **Результаты:**
  - Максимальная разность между выходом PyTorch Conv2d и `cv2.filter2D` во `float32` составила ровно $0.00 \times 10^0$.
  - Реализован банк из 4 фильтров (Sobel V, Sobel H, Laplace, Box Blur), извлекающий карты базовых геометрических примитивов за один прямой проход тензора $(1, 4, 303, 384)$.
  - **Анализ параметров:**
    - Слой `nn.Conv2d(3, 32, kernel_size=3, bias=True)` содержит всего **896 весов**.
    - Эквивалентный полносвязный слой (`nn.Linear`) для входа $128 \times 128 \times 3$ и выхода $32 \times 128 \times 128$ требует **$25\,769\,803\,776$ параметров** ($\approx 25.77$ млрд весов).
    - Выигрыш свёртки по памяти составляет **в $28\,760\,942$ раза** благодаря принципу локальной связности и разделения весов (*Weight Sharing*).

### Лабораторная 8: Геометрия свёртки, пулинг и рецептивное поле
- **Цель:** Исследование гиперпараметров (stride, dilation, padding), вычисление размера выхода и расчет теоретического и эмпирического рецептивного поля (RF).
- **Результаты:**
  - Для конфигурации $(H_{\text{in}}=64, k=3, p=2, s=2, d=2)$ теоретический расчет дал:
    $$H_{\text{out}} = \left\lfloor \frac{64 + 4 - 4 - 1}{2} \right\rfloor + 1 = 32$$
    что строго совпало с размером тензора PyTorch $(1, 1, 32, 32)$.
  - **Эмпирическое рецептивное поле:** С помощью механизма `autograd.backward()` от центрального нейрона двух последовательных слоев $3 \times 3$ вычислена маска ненулевых градиентов по входу. Размер зоны влияния составил ровно **$5 \times 5 = 25$ пикселей**, что экспериментально подтвердило аддитивный закон расширения контекста: $RF = k_1 + k_2 - 1 = 3 + 3 - 1 = 5$.

### Лабораторная 9: Мультиклассовая классификация фигур на CNN
- **Цель:** Разработка сквозного пайплайна обучения классификатора фигур (`circle`, `square`, `triangle`) с защитой от data leakage.
- **Архитектура модели:**
  - Feature Extractor: `Conv2d(3, 16, 3, p=1)` $\to$ `BatchNorm` $\to$ `ReLU` $\to$ `MaxPool(2)` $\to$ `Conv2d(16, 32, 3, p=1)` $\to$ `BatchNorm` $\to$ `ReLU` $\to$ `MaxPool(2)`.
  - Classifier Head: `AdaptiveAvgPool2d((4, 4))` $\to$ `Flatten` $\to$ `Linear(512, 64)` $\to$ `ReLU` $\to$ `Dropout(0.2)` $\to$ `Linear(64, 3)`.
- **Протокол обучения:** 8 эпох, оптимизатор Adam ($\text{lr} = 1.5 \times 10^{-3}$), функция потерь Cross-Entropy.
- **Результаты:**
  - Train Accuracy: $76.5\%$ | Val Accuracy: $65.2\%$ | Test Accuracy: $63.89\%$.
  - Анализ Confusion Matrix показал абсолютную безошибочность на классе `circle` и наличие взаимных ошибок `square` $\leftrightarrow$ `triangle` из-за геометрической близости наклонных ребер при дискретизации сетки $64 \times 64$.

### Лабораторная 10: Семантическая сегментация масок на базе U-Net
- **Цель:** Попиксельная сегментация геометрических масок $96 \times 96$ с использованием архитектуры Compact U-Net со связями проброса (*Skip Connections*).
- **Архитектура Compact U-Net:**
  - Двухуровневый энкодер с промежуточным пулингом ($96 \to 48 \to 24$).
  - Bottleneck на 64 канала.
  - Декодер с билинейным апсэмплингом и конкатенацией skip-связей для сохранения тонких границ.
  - Функция потерь: `BCEWithLogitsLoss`.
- **Результаты на валидации (24 независимые пары):**

| Порог отсечения $\tau$ | Mean IoU (Jaccard) | Mean Dice (F1) | Качество сегментации |
| :---: | :---: | :---: | :--- |
| $\tau = 0.3$ | $0.3101$ | $0.4693$ | Захват низкоамплитудного фонового шума |
| **$\tau = 0.5$** | **$0.9861$** | **$0.9930$** | **Высочайшая точность совпадения контуров** |
| **$\tau = 0.7$** | **$0.9994$** | **$0.9997$** | **Практически идеальная реконструкция масок** |

Визуализация показала идеальное восстановление топологии и геометрии фигур, подтвердив эффективность skip connections.

## 5. Инструкция по установке и воспроизведению

### 5.1. Клонирование и установка зависимостей
```bash
git clone https://github.com/Sakha-kz/car_MMCV.git
cd car_MMCV/Pra_30.10.26
pip install -r requirements.txt
```

### 5.2. Автоматический запуск тестирования математического ядра
Для выполнения всех тестов модуля `student_ops.py` и генерации графиков в папку `output_bonus_results/`:
```bash
python test_student_ops.py
```

### 5.3. Пакетное исполнение всех 10 Jupyter-ноутбуков
Для обновления кодовых ячеек, сквозного исполнения и сохранения графиков в структуре `.ipynb`:
```bash
python runner.py
```
