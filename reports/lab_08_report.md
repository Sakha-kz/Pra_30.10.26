# Отчет по лабораторной работе №8
## Тема: Stride, pooling, dilation и рецептивное поле

### 1. Цель работы
Исследовать влияние гиперпараметров свертки (шаг дискретизации `stride`, расширение `dilation`, дополнение `padding`, размер ядра `kernel_size`) и операций субдискретизации (`MaxPool2d`, `AvgPool2d`) на пространственный размер карт признаков, изучить феномен рецептивного поля (Receptive Field) нейронов, а также вычислить эмпирическую область влияния с помощью механизма автоматического дифференцирования PyTorch Autograd.

### 2. Используемые данные
- `images/source/checkerboard.png` (тестовая шахматная доска $200 \times 200$);
- `images/source/fine_stripes.png` (периодические высокочастотные полосы);
- Синтетические тензоры $15 \times 15$ и $64 \times 64$ для точной верификации градиентных потоков.

### 3. Краткая теория и математический аппарат
1. **Каноническая формула пространственного размера выхода свертки**:
   $$H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2p - d(k - 1) - 1}{s} \right\rfloor + 1$$
   где $p$ — padding, $s$ — stride, $d$ — dilation, $k$ — kernel size.
   Для $H_{\text{in}}=64, k=3, p=2, s=2, d=2$:
   $$H_{\text{out}} = \left\lfloor \frac{64 + 2\cdot 2 - 2(3-1) - 1}{2} \right\rfloor + 1 = \left\lfloor \frac{64 + 4 - 4 - 1}{2} \right\rfloor + 1 = \left\lfloor 31.5 \right\rfloor + 1 = 31 + 1 = 32.$$
2. **Пулинг (Pooling)**:
   - `MaxPool2d`: отбирает максимальную активацию в скользящем окне, обеспечивая слабую инвариантность к малым деформациям и сдвигам;
   - `AvgPool2d`: вычисляет среднее арифметическое, сглаживая текстурные перепады.
3. **Разреженная (Dilated / Atrous) свёртка**: Вставляет $d - 1$ нулей между элементами ядра. Эффективный размер ядра возрастает до $k' = d(k - 1) + 1$, позволяя охватывать больший контекст без увеличения числа параметров.
4. **Теоретическое и эффективное рецептивное поле (RF)**:
   - Для последовательности двух слоев $3 \times 3$ с шагом $s=1$: $RF_1 = 3$, $RF_2 = RF_1 + (k_2 - 1) = 3 + 2 = 5$. Размер рецептивного поля составляет $5 \times 5 = 25$ пикселей.
   - Эффективное рецептивное поле (ERF) имеет гауссово распределение плотности градиента, быстро затухая от центра к краям.

### 4. Результаты выполнения и код
- Выполнен `MaxPool2d(2)` и `AvgPool2d(2)` на изображении шахматного поля: на границах клеток средний пулинг формирует серые промежуточные пиксели, а максимальный пулинг сохраняет резкие белые значения.
- Численно проверена формула $H_{\text{out}}$ для конфигурации $(k=3, p=2, s=2, d=2)$ на входе $64 \times 64$: результат аналитического расчета ($32 \times 32$) строго совпал с фактической формой тензора PyTorch `(1, 1, 32, 32)`.
- С помощью обратного распространения ошибки (`autograd.backward`) от центрального нейрона двухслойной сети ($3 \times 3 \to 3 \times 3$) построена маска ненулевых частных производных $\frac{\partial y}{\partial x}$:
  - Размер ненулевой области составил ровно $5 \times 5 = 25$ пикселей, подтвердив теоретический закон сложения рецептивных полей $RF = k_1 + k_2 - 1$.
- Исследовано поведение слоев со `stride=2` на текстуре `fine_stripes.png`: подтверждено возникновение алиасинга при агрессивном сжатии без сглаживания.

### 5. Вывод
В ходе лабораторной работы детально исследована геометрия сверточных преобразований в глубоких нейросетях. Установлена математическая строгость канонической формулы вычисления выходного размера карты признаков при любых сочетаниях stride, padding и dilation. Доказано, что применение расширенной (дилятированной) свертки позволяет экспоненциально наращивать рецептивное поле нейронов верхних уровней без увеличения числа обучаемых параметров и без потери пространственного разрешения (что критично для задач сегментации и детекции). Эксперимент с автодифференцированием наглядно подтвердил, что рецептивное поле каждого последующего слоя аддитивно расширяется на $(k-1)$ пикселей при единичном шаге. Выявлены фундаментальные различия между Max-pooling и Avg-pooling: первый выделяет наиболее выраженные доминантные признаки, а второй производит равномерную пространственную интеграцию энергии сигнала. Полученные знания являются ключевыми для грамотного проектирования архитектур современных нейросетей.
